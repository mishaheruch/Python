## Завдання

Напиши скрипт на Python, який буде працювати не в інтерактивному режимі, а через командний рядок. Цей скрипт має називатися `schedule_cli.py`. Він має приймати дві команди: `add` и `list`. Перша команда також має приймати час і назву уроку. Друга команда виводить список всіх доданих уроків. Уроки зберігай у файлі. Формат збереження даних обери сам. Подумай про те, що тобі треба буде потім прочитати дані з цього файлу і вивести їх. У файлі не має зберігатися нічого, крім назви уроку і часу. Якщо файл пустий або не існує, має виводитися повідомлення про це.

### Приклад використання:

```
schedule_cli.py add 10:30 Biology
Урок 1 успішно додадно: Biology, час 10:30
```

```
schedule_cli.py list
Розклад уроків на завтра (усього 2 урока)
Урок 1 – Biology, час 10:30
Урок 2 – Math, час 12:30
```
