# Робота з файлами. Продовження.

## Завдання

Папка `data` містить файли у форматі CSV. Кожен файл містить інформацію про людей у певній послідовності. Тобі потрібно написати скрипт (назву придумай сам), який проаналізує усі файли і порахує кількість людей, у яких `Hire Date` після 1 березня 2020 року. Крім того, потрібно згрупувати дані за штатом проживання (поле `State`) та порахувати кількість людей для кожного штату (вивести штати у алфавітному порядку).

## Приклад роботи:

```
python3 {твій_скрипт}.py
Результат аналізу даних:
27 осіб було найнято на роботу після 1 березня 2020 року
Розподіл за штатом проживання:
Alabama: 3
Maryland: 10
New Jersey: 7
...
і так далі
```

### Підказки

- пошукай, як найкраще працювати із CSV файлами у Python
- в модулі `os` є методи для роботи з папками і файлами, які допоможуть тобі дістати імена файлів, які треба проаналізувати
- використовуй цикли і вже знайомі тобі структури даних (list, tuple, dict), щоб зберігати та аналізувати те, що ти прочитаєш із файлів
   

   1 підключити бібліотеки
   2 знайти віткрити файл прочитати 
   3 створити контрольну дату 
   4 порахувати людей 
   5 вивести результати на екран
